# Content Engine Assets

Central public asset repository for the Content Engine.

## Purpose

This repository stores publication-ready visual assets that may be reused across websites, Google Business Profile, social media, blog content and other publishing channels.

Assets are organised by project and asset type, not by publishing channel. When possible, the private Google Drive archive uses the same relative path and filename.

## Structure

- `altio/site/`
- `altio/realisations/`
- `altio/generated/`
- `askit-ai/site/`
- `askit-ai/generated/`
- `falcification/site/`
- `aphotographie/portfolio/`

## Rules

- Public assets only. Never add confidential or user-provided documents.
- For A. Photographie, only use photographs already published on aphotographie.ch.
- For FALCification, never add user documents or customer content unless explicitly provided for publication.
- Keep filenames descriptive, lowercase and hyphenated.
- Avoid duplicate assets. Reuse the same file across channels and track usages in the manifest.
- No open-source license is granted for the visual assets in this repository.
